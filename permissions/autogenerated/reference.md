## Default Permission

Allows the seven Jelto SDK operations. Grant only to chosen local application windows. Collection still requires explicit init.

#### This default permission set includes the following:

- `allow-init`
- `allow-track`
- `allow-onboarding`
- `allow-set-props`
- `allow-install-id`
- `allow-reset`
- `allow-disable`
